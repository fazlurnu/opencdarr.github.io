# Environments

The [modules](../modules/index.md) define the pieces; an *environment* is how they are exercised. Each sets up traffic that would otherwise collide, runs it to termination, and measures how separation holds up — the same directed, pairwise-primitive core, scaled from two aircraft to many.

- **[Pairwise conflict](pairwise.md)** — a single encounter between two aircraft. The simplest setting for studying detection and resolution, and where the geometry is swept one variable at a time.
- **[Multi-aircraft conflict](multi-aircraft.md)** — many aircraft at once, each avoiding all the others with no central controller. The cooperative fleet, and where the hard cases appear.

For one worked encounter from start to finish, see [A first run](../first-run.md).
