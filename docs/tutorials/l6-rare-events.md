# L6 · Rare events

!!! note "In preparation"
    The L6 notebooks are being written. The plan below is the commitment; the [curriculum document](https://github.com/fazlurnu/OpenCDaRR/blob/main/docs/curriculum.md) holds the live version.

Below roughly one in a thousand, counting stops working: the events you need to see stop arriving. This level makes you feel that wall with plain Monte Carlo first, then walks through the interacting particle system that gets past it — and, just as important, the test that tells you the clever estimator agrees with the plain one where both can see.

The planned lessons:

- **Where counting stops** — the cost of a rare event under plain sampling, measured live.
- **IPS** — the interacting particle system, run once end to end.
- **The shell ladder** — the intermediate separations, and how the survival fractions multiply into a rare probability.
- **The MC anchor test** — validate IPS against Monte Carlo in the regime where Monte Carlo still works.
- **Parallel** — spreading the estimate over cores without breaking reproducibility.
