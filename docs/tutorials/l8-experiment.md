# L8 · The full experiment

!!! note "In preparation"
    The L8 notebooks are being written. The plan below is the commitment; the [curriculum document](https://github.com/fazlurnu/OpenCDaRR/blob/main/docs/curriculum.md) holds the live version.

The capstone. One research question carried from its first sentence to a report someone else could act on — with every level above doing the work it was learned for.

The planned lessons:

- **The question** — writing a question an experiment can actually answer.
- **Sizing from a pilot** — a small pilot run, and turning its spread into the batch size the real run needs.
- **The config file** — the experiment as one reviewable declaration.
- **The campaign script** — running the conditions, resumably and reproducibly.
- **The report** — the figures, the intervals, and the sentence the question deserves.

The two case studies — [pairwise conflict](../handbook/experiments/example-pairwise-conflict.md) and [random traffic](../handbook/experiments/example-random-traffic.md) — are finished examples of exactly this arc; read them before you start and they become the model answer.
